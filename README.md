# Chart Movie - IMDb Data Visualization

An interactive bubble chart visualization that explores IMDb movie ratings by start year, number of votes, average rating, and genre.

## Overview

This project visualizes IMDb movie data using Chart.js, displaying movies as bubbles on a scatter plot where:
- **X-axis**: Start Year
- **Y-axis**: Number of Votes
- **Bubble size**: Average Rating

Each genre is displayed as a separate colored dataset, allowing users to explore how different genres compare across time and popularity.

## Features

- **Bubble Chart Visualization**: Movies represented as bubbles sized by average rating
- **Genre Filtering**: Sidebar buttons to filter by specific genres (Adult, Drama, Comedy, Short, Documentary, Family, Adventure, Action, Unknown, Horror, Crime, Romance, Musical, Animation, Biography, Thriller, Fantasy)
- **Interactive Tooltips**: Hover over bubbles to see movie details (title, genre, year, votes, rating)
- **Reset Button**: Show all genres at once

## Data

The project uses IMDb dataset containing movie information including:
- Original title
- Start year
- Number of votes
- Average rating
- Genre categories

## Tech Stack

- HTML/CSS
- JavaScript
- Chart.js (v4.5.1)
- IMDb Dataset
